# العصر الحجري · البرستيج 1 — القسم 1: النار والوقود (`v1.0.0`)

مشروع Android ثلاثي الأبعاد (Kotlin + OpenGL ES 3.0) جاهز للبناء الفوري عبر **GitHub Actions**، ينفذ **القسم الأول كاملاً (10 مصانع مترابطة × 5 آلات = 50 آلة)** بوضع عمودي وكاميرا ثلاثية الأبعاد بأسلوب Clash of Clans.

## الميزات المنجزة في `v1.0.0`
- **بيانات معيارية 100% من JSON (`app/src/main/assets/data/stone_age_sec1.json`):** المصانع الـ 10 كاملة بالترتيب (حطب مجفف → فحم نباتي → قوالب وقود → جمر محفوظ → مشاعل → سراج دهني → حجارة حرارية → موقد حجري → فرن حفرة → نار المجتمع) مع 50 آلة مصنّفة ضمن النماذج الـ 12 الأساسية (`Archetypes`).
- **كاميرا Clash of Clans ثلاثية الأبعاد (`ClashCamera.kt`):** منظور 3/4 مائل، سحب سلس بإصبع واحد مع قصور ذاتي (Inertia)، تكبير/تصغير بإصبعين (Pinch Zoom)، ونقر دقيق على أي مصنع في المشهد ثلاثي الأبعاد.
- **مؤشر عنق الزجاجة البصري + الشحن الفائق + الجمرة الذهبية:** توهج برتقالي نابض على أبطأ آلة في كل مصنع، زر `⚡ 2×` للشحن الفائق 15 ثانية، ومكعب جمرة ذهبية عائم للمكافآت الفورية.
- **الاقتصاد والحفظ:** صنف `BigNumber` (mantissa + exponent)، تكلفة `base * 1.15^level`، مضاعف `×2` كل 25 مستوى، حفظ ذري مرقم (`save_version = 1`)، وحساب أرباح الغياب (Offline Earnings حتى 4 ساعات).
- **جاهز لاستبدال المجسمات لاحقاً:** جميع الآلات مبنية على الـ 12 `Archetypes` عبر `ProceduralMeshes.kt` و `FactoryRenderer.kt`، ويمكن استبدال كل Archetype بنموذج `.glb` من Blender لاحقاً دون تعديل منطق المحاكاة.

## طريقة البناء على GitHub Actions (خطوتان فقط)
1. فك ضغط هذا المشروع وارفعه إلى مستودع GitHub جديد (أو موجود) على فرع `main`.
2. افتح تبويب **Actions** في GitHub، سيعمل `Build Stone Age Factory APK` تلقائياً خلال ~2 دقيقة ويعطيك ملف **`StoneAgeFactory-v1.0-debug-apk`** جاهزاً للتثبيت مباشرة على هاتفك Android.
